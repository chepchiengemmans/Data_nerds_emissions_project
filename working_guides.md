## Guide for creating & using your branch
Clone the repository to your local machine: git clone https://github.com/chepchiengemmans/Data_nerds_emissions_project.git

Create a new branch for your specific feature or fix (never work directly on main): git checkout -b [task]

Make edits, stage, and commit your changes locally: git add .

git commit -m "changes made"

Push the branch to repository: git push origin [task]
